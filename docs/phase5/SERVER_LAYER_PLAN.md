## قرارات (1): `objectKey`
- **المفتاح يُشتق في الخادم فقط.** الواجهة الحالية (`SubmitDialog`) تبني مفتاحًا مؤقتًا بنفسها بـ`pendingKey`؛ هذا مقبول للتخزين الوهمي فقط، ولا يجوز أن يكون مصدر الحقيقة في الخادم. لم أغيّر الواجهة.
- صيغتان: `pending/<teacher>/<term>/<slot>/<sessionId>.<ext>` و`files/<teacher>/<term>/<slot>/v<no>.<ext>`. المؤقت مشتق من رقم الجلسة فيكون إعادة الإتمام بالمفتاح نفسه.
- معرّفات: `[A-Za-z0-9][A-Za-z0-9_-]{0,63}` (بلا نقاط). امتداد: من القائمة المسموحة (الإعداد، غير نهائي). رقم الإصدار: صحيح موجب ≤ 999,999,999 بلا أصفار بادئة. أقصى طول 255.
- `parseObjectKey` يرفض كل ما لا يعيد البناء نفسه حرفيًا؛ `assertKeyInScope` يعزل المعلمات؛ `assertIsPendingKeyOf` يربط المفتاح بجلسته تحديدًا.

## ما وجدته في `src/lib/storage/keys.ts` (فحص فعلي، لم أعدّله)
- **لا ثغرة تسلل مسارات:** `..` و`.` والشرطة المائلة العكسية والمسافات ومحارف التحكم و`%` كلها مرفوضة.
- **لكنه فحص أمان عام لا فحص صيغة:** يقبل `x` و`v01` ونقطة في آخر الاسم و`v1..pdf` وامتدادات مثل `php` وأجزاء طويلة (حتى 512 للمفتاح كله). لذلك أُضيفت الطبقة الخادمية الأصرم فوقه (الخادم يستدعيه أيضًا كطبقة ثانية). تعديله نفسه يمس الواجهة، فتركته بانتظار قراركِ.
- ملاحظة: `newToken()` يعود إلى `Math.random` إن لم يتوفر `crypto.randomUUID`. مقبول لمفاتيح الواجهة المؤقتة، غير مقبول لأي سرّ أو رمز دخول في الخادم.

## حدود ما اختُبر
- الطفرة التي أزالت فحص «إعادة البناء حرفيًا» لم تُكسر الاختبارات: الفحوص السابقة تغطي كل الحالات حاليًا، فهو دفاع إضافي لا يمكن اختباره منفردًا (طفرة مكافئة). لا أدّعي أن الاختبارات تغطيه.
- لم يُشغَّل `vitest` ولا `tsc -b` الكامل ولا `build` (لا `node_modules` ولا سجل npm في بيئتي). اختبار `server/test` مكتوب بصيغة vitest وسيعمل تحت `npm test` عندكِ، وهذا **لم يُجرَّب**.

## على Windows (بالترتيب، بعد استلام هذه الحزمة)
1. فكّي الضغط ثم افتحي PowerShell في مجلد `athar`.
2. `npm install` (لا `npm ci`).
3. `npm test` — يجب أن يشمل ملف `server/test/objectKey.test.ts`. أرسلي لي النتيجة كما هي، ناجحة أو فاشلة.
4. `npm run typecheck`.
5. بديل بلا vitest (يحتاج Node 22 أو أحدث): `node --experimental-strip-types --no-warnings --import ./scripts/node-test-runner/register.mjs --test server/test/objectKey.test.ts`
