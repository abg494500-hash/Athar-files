# تقرير الدفعة (0.6.11، حزمة r20) — R2 بالبدائل، قراءة المعلمة، روابط موقّعة، أرشفة، تركيب، ربط واجهة الدخول (A-102)

> **الحالة بصدق:** البيئة ما زالت بلا PostgreSQL ولا npm ولا شبكة (تحقّقتُ مجددًا). لم يُلمَس Supabase ولا Cloudflare، لا أسرار في أي ملف، **لا جداول ولا أعمدة جديدة**، ومسودة 006 لم تُطبَّق. المرفق الذي وصلني كان نسخة r18 فقط في الرفع، لكن r19 في مساحة الإخراج تطابق شجرتي بايتًا ببايت (تحقّقتُ بـ`diff -rq`) فبنيتُ عليها. **المشروع غير جاهز للمدرسة ولا للنشر.**

## 1) ما اكتمل فعليًا واختُبر (ببدائل)
| البند | الملفات | الدليل |
|---|---|---|
| توقيع SigV4 (ترويسات + روابط مسبقة) | `server/storage/sigv4.ts` | يطابق **متجهَي AWS المنشورين** (مرجع مستقل) |
| محوّل R2 (put بلا استبدال، get، presign PUT/GET، لا حذف) | `server/storage/r2.ts` | fetch وهمي يحاكي S3؛ **لا R2 حقيقي** |
| قراءة المعلمة: فصولها بمواعيد **كل فصل المستقلة**، الخانات، الإصدارات، `canSubmit/canReplace` بساعة القاعدة | `server/services/teacherReadService.ts` | منطق التركيب مُختبَر بصفوف؛ SQL **لم يُشغَّل** |
| روابط الرفع (PUT موقّع بحجم الجلسة) وتنزيل الملفات (معلمة: ملفاتها؛ مالكة/مديرة: أي ملف) | `server/services/transferService.ts` | قاعدة بديلة |
| الأرشفة: creating ← بناء بفشل مغلق ← كتابة ← إعادة قراءة والتحقق ← verified/failed، وتنزيل للمالكة فقط | `server/services/archiveService.ts` | قاعدة وتخزين ذاكرة بديلان؛ اختُبر تلف التخزين عند إعادة القراءة |
| مسارات HTTP الجديدة: `/teacher/portfolio`، `/teacher/uploads/presign`، `/teacher/downloads/sign`، `/staff/downloads/sign`، `/owner/archives/{create,download}` | `server/api/handler.ts` | تفويض الأدوار مُختبَر (المديرة 403 على الأرشفة، المعلمة 401 على مسارات الموظفات) |
| تركيب كل الخدمات من إعدادات تُحقن (فشل مغلق، لا قيم في الأخطاء) | `server/api/compose.ts` | إعدادات وهمية؛ لم يُركَّب على مضيف |
| عميل المعلمة: portfolio وsignDownload (https فقط) | `src/lib/teacherAuth/client.ts` | fetch وتخزين بديلان |

أرقام: مشغّل Node **318/318** (266 + 52)، `tsc --strict --noUnusedLocals` نظيف على ملفات `server/` الجديدة والعميل (مترجم TypeScript 6.0.3 المحلي، **لا سلسلة المشروع**)، SQL ساكن 39/39 و30/30. **اختبار طفرات:** 14 كسرًا عمديًا للشيفرة الجديدة؛ 13 أُمسكت (واحد لم يُمسك أولًا فأضفتُ اختبار تلف التخزين)، والأخير (توسيع شرط تحديث failed) سلوكه مكافئ على الأرجح ولم أعدّه ضمانًا.

## 2) كُتب ولم يُجمَّع ولم يُختبر (واجهة React)
`Login.tsx` (تبويب المعلمة يعرض نموذج الكود والرقم السري **فقط** عند ضبط `VITE_TEACHER_API_URL`، وإلا تبقى «غير متاح بعد» كما كانت)، `TeacherPortalContext.tsx` (جلسة المعلمة معزولة عن Supabase)، `pages/teacher/Portal.tsx` (بوابة قراءة وتنزيل: الفصول، المواعيد، الخانات، الإصدارات)، `App.tsx` (مسار `/teacher/portal` خارج `Guard` وDataGate)، `src/test/teacherPortal.test.tsx`. راجعتُ استيراداتها وأنواعها يدويًا مقابل مكوّنات المشروع، لكن **لا تفترضي أنها تُجمَّع**: أول `typecheck` و`vitest` لها على جهازكِ، وأرسلي لي الأخطاء.

## 3) ما لم يُنجَز من قائمتكِ
| المهمة | الوضع |
|---|---|
| ربط دخول المعلمة **ربطًا حقيقيًا** | الواجهة والعميل والخدمات والمسارات مبنية، لكن **لا دخول فعلي ممكن بعد**: لا مضيف منشور، ولا مشغّل Postgres إنتاجي، ومسودة 006 غير مطبّقة (انتظار موافقتكِ) |
| رفع/استبدال/إلغاء من واجهة المعلمة | خدمات ومسارات جاهزة (start/presign/complete/cancel + بوابة المواعيد)؛ **غير مربوطة بالواجهة** لأن R2 لم يُجرَّب فعليًا |
| R2 حقيقي | **لم يُجرَّب**؛ قائمة التجربة في `R2_INTEGRATION_AR.md` |
| تنزيل الملفات من صفحات الإدارة | المسار جاهز (`/staff/downloads/sign`)؛ صفحات الإدارة الحالية (بيانات Supabase/الوهمي) لم تُعدَّل |
| صفحة أرشيف المالكة | المسارات جاهزة؛ الصفحة لم تُربط |
| اختبار SQL على PostgreSQL محلي | غير ممكن هنا؛ كل SQL الجديد غير مُشغَّل |
| ملفات كبيرة في الأرشيف | البناء بالذاكرة (لا تدفق) — قيد موثّق |

## 4) قرارات تنتظركِ (توقفتُ عندها ولم أغيّر شيئًا)
1. **مسودة `006_teacher_sessions`:** لا يعمل دخول المعلمة على قاعدة حقيقية بدونها. هل توافقين على تطبيقها (محليًا أولًا)؟
2. **افتراض DP-03:** رفع مباشر إلى R2 بـPUT موقّع ثم إتمام خادمي يقيس الكائن. هل يناسبكِ؟ (البديل: رفع عبر الخادم.) وهل مدد الروابط (رفع ≤ 15 د، ملف 60 ث، أرشيف 120 ث) مقبولة؟
3. **ضبط R2 وCORS** في حسابكِ (حاوية خاصة ومفتاح محصور بها): تغيير إعدادات خارجية لن أجريه دون موافقتكِ — أو تجريه أنتِ ثم نجرّب.
4. **استضافة الواجهة الخادمية** (Edge/Worker) ومشغّل Postgres إنتاجي: لم أنشر شيئًا؛ أحتاج قراركِ على المنصة.
5. من أفرجت عن الجلسة (أثر دائم): يحتاج عمودًا/جدولًا، لم أضفه. وملء `archive_entries` و`versions.archive_id` مؤجّل لحين مسار الحذف النهائي.
6. مخطط مسارات الأرشيف (معرّفات فقط افتراضًا) والاسم الأصلي في البيان؛ وقرارات §9 القديمة.
