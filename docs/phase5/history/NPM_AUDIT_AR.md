# ثغرات npm (11 مُبلَّغ عنها) — ما أعرفه، وما لا أستطيع تأكيده، وكيف نقرّر (r23)

> **صدق أولًا:** `npm audit` يحتاج الوصول إلى سجل npm، وبيئتي بلا شبكة ولا ذاكرة تخزين (جرّبتُ `npm ci --offline` فرفض: `ENOTCACHED`). **لذلك لا أستطيع تحديد الثغرات الإحدى عشرة ولا خطورتها.** لن أخمّن أسماء حزم أو أرقام ثغرات. ما يلي: ما يمكن معرفته من ملفات الحزمة، وأداة تحوّل تقريركِ الحقيقي إلى جدول قرارات، وقواعد القرار.

## 2) كيف نحصل على الصورة الحقيقية (على جهازكِ)
```
npm audit --json > audit.json
npm audit --omit=dev --json > audit-prod.json
node --experimental-strip-types --no-warnings scripts/summarize-npm-audit.mjs audit.json > audit-summary.md
```
الأداة (`server/tools/auditSummary.ts`) **لا تطبّق أي إصلاح ولا تتصل بشبكة**: تقرأ `audit.json` و`package-lock.json` وتعطي جدولًا عربيًا لكل حزمة: الخطورة، **إنتاج/تطوير**، مباشرة أم متعدية، المثبَّت، **هل الإصلاح كاسر**، وعنوان الثغرة ورابطها، مع توصية. تخرج بالرمز 1 إن وُجدت ثغرة عالية/حرجة في الإنتاج. اختُبرت على تقرير **تركيبي** فقط (5 اختبارات، وأمسكت خطأ ترتيب حقيقيًا في نسختها الأولى). أرسلي لي `audit-summary.md` (أو `audit.json`) وأحلّله معكِ.

## 3) قواعد القرار (لن أخرقها)
1. **لا `npm audit fix --force` إطلاقًا**، ولا تحديث رئيسي (major) دون تحليل وفرع منفصل واختبارات كاملة.
2. **الإنتاج أولًا:** عالية/حرجة في الإنتاج ⇒ تمنع النشر حتى تُعالَج أو يُوثَّق سبب عدم قابلية استغلالها في تطبيقنا (SPA ثابت، لا SSR).
3. **التطوير:** لا تمنع النشر، لكن لا تشغّلي `npm run dev` على شبكة عامة ولا تفتحي منفذه للخارج؛ وتُخطَّط ترقية دورية (vite/vitest) كعمل مستقل.
4. **غير الكاسر:** يُجرَّب على فرع (`npm audit fix` بلا `--force` أو `npm update <الحزمة>`)، ثم `typecheck` و`npm test` و`npm run build`، ثم يُدمج.
5. **الكاسر:** يُقرَّر بعد قراءة سجل تغييرات الحزمة (مثل react-router 6→7: تغيّر واجهات الراوتر وإعادة اختبار كل المسارات) ولا يتم ضمن دفعات الميزات.
6. أي تجاوز مؤقت يُسجَّل في `DECISIONS_LOG.md` بسببه وتاريخ مراجعته.

## 4) ما سأفعله حين أستلم التقرير الحقيقي
أصنّف الإحدى عشرة (إنتاج/تطوير/كاسر/غير كاسر)، أحدّد ما يمس تطبيقنا فعلًا، وأقترح ترتيب المعالجة، وأجرّب غير الكاسر في بيئتكِ عبر أوامر دقيقة تنفّذينها وتعيدين لي نتائجها. **لم أغيّر `package.json` ولا `package-lock.json` في هذه الدفعة.**
