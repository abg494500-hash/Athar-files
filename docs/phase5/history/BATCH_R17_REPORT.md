# تقرير الدفعة (0.6.8، حزمة r17) — محاكي القاعدة المحلي وخدمات الرفع (A-99)

> **الحالة بصدق:** كل ما يلي **نُفِّذ فعليًا** على PostgreSQL 16 محلي مؤقت (ليس Supabase). **لم يُلمَس Supabase ولا أي خدمة حقيقية؛ لم يُجرَّب تسجيل دخول حقيقي ولا رفع إلى مزوّد تخزين حقيقي.**

## 1) ما وجدته في الحزمة r16 (فحص قبل البدء)
منجز: واجهة المالكة/المديرة، دخولهما (بلا TOTP)، SQL 001–005 + حزمة `supabase/`، المنطق المرجعي `src/lib/upload` و`src/lib/storage`، `server/objectKey.ts`. غير موجود: أي محاكي قاعدة، خدمات الرفع، دخول المعلمة، اختبار ZIP. (مطابق لتقرير r16).

## 2) ما أُنجز في هذه الدفعة
1. **تشغيل SQL فعلي لأول مرة في هذه البيئة** (Postgres 16 محلي): `tests/sql` الثلاثة **62/62 و57/57 و36/36**. أُضيف تشغيل 005 + `25_staff_accounts_005.sql` إلى `run-sql-tests.sh` (دورة ثالثة c) وقبول مسار socket محلي.
2. **حزمة `supabase/` المولَّدة** (01 + 01b + 02 + 03) شُغّلت محليًا بـ`auth.uid()` محاكى: **02: PASS=98 FAIL=0، و03: 8/8 PASS**، أي لا أثر باقٍ (السجل: `tests/sql/results/supabase_pack_local.log`). تنبيه: بمحاكاة `auth.uid()` بسيطة تعتمد `app.uid` ظهرت 11 إخفاقًا مصطنعًا؛ هي من المحاكاة لا من SQL، وزالت بمحاكاة تقرأ `request.jwt.claims` كما تفعل Supabase.
3. **محاكي القاعدة** (`server/db/*`) + اختباراته (6): انظر `SERVER_DB_EMULATOR.md`. **PGlite لم يُستعمل لحجب npm** (السبب والبديل موثقان).
4. **خدمات الرفع** `server/services/uploadService.ts`: `start`، `complete`، `cancel`، `saveLink`، `sweepExpired`، `recoverStuck`، مع `gate.ts` (حالة التسليم من المواعيد) و`observe.ts` (قياس الكائن الفعلي) و`errors.ts`.
   - المفتاح المؤقت يُشتق خادميًا؛ الأزمنة من ساعة القاعدة؛ الإعدادات (الحجم/الأنواع/النافذة) من `app_settings`.
   - الإتمام: قياس الحجم وSHA-256 والتوقيع من البايتات الفعلية، **نسخ إلى المفتاح النهائي `files/.../v<no>`** من البايتات المقيسة نفسها (يحمي من التبديل بعد التحقق)، ثم تسجيل الإصدار ذرّيًا (جلسة ← إصدار ← accepted) تحت قفل الخانة. أي تعطل بين الخطوات يترك الجلسة `uploaded` للاستئناف (لا رفض بالتأخير).
   - الروابط: https فقط، بلا بيانات اعتماد، ≤2048، نطاق بنقطة؛ تكرار الرابط الأخير يعيد الإصدار نفسه؛ ترقيم الإصدارات متتابع مع الملفات.
5. **عزل المعلمات**: جلسة غيرها أو مجهولة أو بمعرّف مشوّه ⇒ `not_found` وتُسجَّل `denied`.

## 3) الاختبارات (فعلية)
- مشغّل Node مع PG: **190/190** (153 سابقة + 37 جديدة: 5 مواعيد وروابط، 6 مشغّل، 26 خدمات). بلا PG: 165/165 (اختبارات القاعدة تُتخطّى).
- الخدمات تُقارَن بالمحاكي المرجعي `UploadLedger` في 3 سيناريوهات: **النتائج وسجل المحاولات متطابقان حرفيًا**.
- تزامن حقيقي (اتصالات متوازية): بدء ×6 بالمفتاح نفسه ⇒ جلسة واحدة؛ بدء ×6 بمفاتيح مختلفة ⇒ جلسة نشطة واحدة؛ إتمام ×5 ⇒ إصدار واحد؛ إتمام + رابطان بالتوازي ⇒ أرقام 1،2،3 بلا ثقوب.
- طفرات (تعمّد كسر الخدمة): 8 طفرات؛ 7 أُمسكت مباشرة، والثامنة (غياب فحص حالة الجلسة قبل التسجيل) لم تُمسك فأُضيف اختبار إفراج أثناء القياس فأُمسكت. الاستقرار: 5 تشغيلات متتالية ناجحة.
- `tsc --strict` على `server/` كاملًا (بما فيه الاختبارات بتعريف vitest مبسّط): نظيف. فحصا SQL الساكنان: **39/39 و30/30**.

## 4) ما لم يُنفَّذ / لم يُختبر
- **vitest الكامل و`npm run typecheck` و`build` للمشروع**: لم تُشغَّل (لا npm). أُضيف `@types/node` إلى devDependencies و`"node"` إلى `tsconfig.types` لأن `server/` صار يستعمل `node:child_process`؛ **لم أتحقق منه في بيئتكِ** — شغّلي `npm install` (لا `npm ci`) ثم `npm run typecheck` وأرسلي الناتج.
- دخول المعلمة (العمل 4)، اختبار ZIP/الأرشفة (العمل 5)، `overview` للخدمة، إفراج المالكة كخدمة (`ownerRelease`)، الاستعادة.
- مزوّد تخزين حقيقي (R2) وأي رفع فعلي؛ حد 50 MB؛ قياس T0/T1.
- مصادقة حقيقية على Supabase؛ التطبيق على Supabase الحقيقي.

## 5) قرارات وملاحظات تحتاج انتباهكِ
1. **بقايا نسخة نهائية بمحتوى مختلف** (انقطاع بعد النسخ ثم إفراج ورفع ملف آخر لنفس الإصدار): لا حذف (A-44)، فتبقى الجلسة `uploaded` بسبب `final_key_conflict` ظاهرًا في `upload_attempts` وتحتاج قرارًا يدويًا. نادرة لكنها حقيقية؛ **قرار معلّق** (مرتبط بـD-11).
2. **الروابط بلا سجل محاولات**: قيد `outcome` في 004 لا يتسع لها؛ النجاح يُدوَّن في `audit_log` والرفض لا يُدوَّن. تغيير القيد يحتاج موافقتكِ.
3. استبدال بعد انتهاء مهلة التسليم المتأخر وقبل مهلة الاستبدال مسموح، وحالته حالة أول إصدار (قاعدة C-09 الخيار A كما في الواجهة).
4. الخدمة **تثق بـ`teacherId` الممرَّر**؛ ربطها بدخول المعلمة هو العمل 4.

## 6) كيف تُشغّلين (Linux/macOS، بعد تثبيت PostgreSQL 15+)
```
sh scripts/local-pg.sh start
eval "$(sh scripts/local-pg.sh env)"
sh tests/sql/run-sql-tests.sh && sh scripts/node-test-runner/run.sh
sh scripts/local-pg.sh stop
```
