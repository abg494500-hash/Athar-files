# تقرير الدفعة التكميلية (0.6.13، حزمة r22) — مشغّل القاعدة ومضيف الخادم وإغلاق ثغرات التشغيل (A-104)

> **الحالة بصدق:** البيئة ما زالت بلا PostgreSQL ولا npm ولا Deno ولا شبكة (جُرّب فعليًا: `npm view` لا يردّ، ولا `psql` ولا `deno`). لذلك **لم يُنفَّذ typecheck ولا vitest ولا build بأدوات المشروع، ولم يُشغَّل أي كود في Deno، ولم يُشغَّل أي SQL، ولم يُجرَّب R2**. لم أتصل بـSupabase ولا Cloudflare ولم أنشر شيئًا، ولا أسرار في أي ملف. نسخة r21 الأصلية محفوظة دون تعديل في `previous-versions/`. المرفق في الرفع كان r18؛ بنيتُ على شجرة r21 التي سلّمتُها. **المنصة غير جاهزة للمدرسة ولا للنشر.**

## 3) الاختبارات: الحقيقي مقابل البديل
- **مشغّل Node البديل: 377/377** (346 + 31 جديدًا). **ليس vitest.**
- **`tsc --strict --noUnusedLocals`** نظيف على كود الخادم والعملاء ونقطة دخول Deno (بتعريف بديل لـ`postgres` و`Deno`)، بمترجم محلي لا بسلسلة المشروع.
- **فحص نوعي لصفحات React بتعريفات بديلة** (react/router/lucide بلا أنواع حقيقية) نظيف، **ولا يلتقط أخطاء أنواع React نفسها ولا يتحقق من وجود أسماء الأيقونات في `lucide-react` المثبّت (`Unlock`, `Wrench`, `Link2`, `Upload`, `RefreshCw`…)**.
- **فحوص ساكنة:** SQL 39/39 و30/30 و28/28؛ توافق عبارات الخادم مع المخطط (نظيف، وأمسك 3/3 كسور عمدية)؛ الأسرار 10/10؛ المولَّد مطابق للمصدر.
- **اختبار طفرات** على الكود الجديد: 11 كسرة؛ كلها أُمسكت بعد تشديد اختبار واحد (طول الجسم المعلن) وتحييد أثر فحص المولَّد في القياس.
- **لم يُشغَّل إطلاقًا:** vitest الكامل، `npm run typecheck`, `npm run build`، اختبارات الواجهة (`teacherPortal.test.tsx`)، أي كود في Deno، أي SQL، R2، Supabase، Windows.

## 4) ما يمنع الدخول والرفع والاستبدال والتنزيل والأرشفة الحقيقية الآن (بالترتيب)
1. **SQL غير منفَّذ** (001–007): لا جداول. أول تنفيذ متوقع فيه أخطاء (004، `log_audit_as`، حارس الأرشيف، SQL الخدمات).
2. **الدالة غير منشورة** وأسرارها غير مضبوطة (R2، أسرار الخلط، الأصل المسموح).
3. **R2 غير مضبوط ولا مجرَّب** (الحاوية، المفتاح، CORS لـPUT وGET، دعم `If-None-Match` وتوقيع `content-length`).
4. **لا حسابات مسؤولين** (تُنشأ من لوحة Supabase ثم `bootstrap_staff`)، ولا أكواد معلمات (تُصدَر من الواجهة بعد 1–3).
5. **صفحات React لم تُجمَّع قط** (توقعي أخطاء typecheck؛ أول ما يُصلح).
6. **توافق Deno/`npm:postgres`/SSL/تبديل الدور/ترويسة العنوان/زمن PBKDF2 غير مُجرَّب** (`EDGE_HOST_AR.md` §6).

## 5) ما بقي من الأعمال البرمجية (لا يمنع التجربة لكنه لازم قبل المدرسة)
أرشفة سنة كاملة عبر الخادم؛ تدقيق دائم لأحداث المعلمة؛ جدولة تلقائية للتنظيف؛ تدفق (streaming) للأرشيفات الكبيرة؛ مسار الحذف النهائي وملء `archive_entries`؛ تقييد معدّل لما عدا الدخول؛ مراقبة وتنبيهات؛ اختبار شامل نهاية-إلى-نهاية؛ اختبار أمني وحمل؛ إغلاق القرارات المعلّقة في `HANDOFF.md`.

## 6) ما يحتاج موافقتكِ الصريحة (لم أفعله)
تنفيذ SQL على Supabase، ضبط R2/CORS، ضبط أسرار الدالة، نشر الدالة، إنشاء حسابات المسؤولين، ضبط `VITE_TEACHER_API_URL`. **الخطوة التالية المقترحة:** `docs/WINDOWS_BATCH_R22_AR.md` (typecheck/test/build)، ثم تنفيذ SQL خطوة بخطوة على مشروع تجريبي جديد بحسب `docs/SUPABASE_SETUP_AR.md`، ثم R2، ثم النشر والتجارب (`EDGE_HOST_AR.md` §4).
