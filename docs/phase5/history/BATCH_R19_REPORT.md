# تقرير الدفعة (0.6.10، حزمة r19) — مراجعة r18 وطبقة HTTP وتفويض الأدوار ومُجمِّع الأرشفة (A-101)

> **الحالة بصدق:** البيئة بلا PostgreSQL وبلا سجل npm وبلا شبكة (جُرّب فعليًا: `npm view` و`pip download` و`apt-get download` فشلت). لذلك كل ما يمس القاعدة الحقيقية ما زال **مكتوبًا ولم يُشغَّل**. لم يُلمَس Supabase ولا Cloudflare، ولا أسرار في أي ملف، ولا SQL جديد، ولم تُطبَّق مسودة 006. **المشروع غير جاهز للمدرسة ولا للنشر.**

## 1) مراجعة الحزمة: التقارير مقابل الكود
أعدتُ تشغيل ما يمكن تشغيله: مشغّل Node **223/223** قبل أي تعديل (مطابق لـr18)، وفحصا SQL الساكنان 39/39 و30/30. وطابقتُ يدويًا أعمدة SQL المستعملة في `overview` و`ownerRelease` مع `database/001` و`004` (كلها موجودة).

| البند | ما يقوله r18 | ما وجدته في الكود | الحكم |
|---|---|---|---|
| دخول المعلمة (كود/PIN/جلسة/قفل) | منطق مكتمل | `teacherAuth.ts` و`teacherCrypto.ts` موجودان ومختبَران على مخزن ذاكرة | **مكتمل منطقًا؛ لم يُجرَّب على قاعدة** |
| `PgAuthStore` + مسودة 006 | مكتوب ولم يُشغَّل | موجود؛ اختباره **نائب لا يختبر شيئًا** دون `ATHAR_TEST_PG` | **مكتوب فقط** |
| `ownerRelease`/`overview` | مسار SQL لم يُشغَّل | موجودان؛ تحقق المدخلات مُختبَر والباقي نائب | **جزئي (مدخلات فقط)** |
| أرشفة ZIP | كاتب/قارئ/تحقق | `zip.ts` مختبَر بأدوات مستقلة | **مكتمل للوحدة؛ لا ربط بالبيانات (أُنجز الآن في r19 مصدرًا ومُجمِّعًا)** |
| رقم 223/223 | «نائب لا يختبر شيئًا» للقاعدة | صحيح: 4 ملفات اختبار قاعدة تمرّ بنائب | **الرقم لا يعني أن SQL اختُبر** |
| التنزيل/روابط موقّعة | لا خدمة | لا شيء في `server/` | **غير موجود** |

**تعارضات صُحّحت:**
1. `docs/RESUME_NEXT_ACCOUNT_AR.md` كان يصف الوضع بعد r17 (يعدّ دخول المعلمة وZIP وoverview «متبقية» ويتوقع 190/190) فتعارض مع r18 → أُعيدت كتابته على r19 مع تنبيه تصحيح.
2. بند «مشغّل Db لـPGlite أو pg» في ذلك الملف أُنجز في r17 (`PsqlDb`) → أُزيل من المتبقي.
3. r18 ذكر أن `issueCredentials` لا تتحقق أن المتصل المالكة → صار التحقق في طبقة HTTP (§2).
4. `TEACHER_LOGIN_DESIGN.md` §7 ما زال يذكر aal2 للمالكة وقد أُلغي بـA-98 (ملاحظة تصحيح أُضيفت في آخره).
5. الأقسام 1–7 في `HANDOFF.md` و`NEXT_STEPS.md` (وصف 0.5.4 والبرومبت الجاهز) **تاريخية قديمة**؛ المرجع الحالي هو الشارات العلوية وهذا التقرير. لم أحذفها (لا حذف للعمل السابق).

لم أكرّر تنفيذ أي وظيفة مكتملة.

## 3) الاختبارات: الحقيقي مقابل البديل
- **حقيقي:** مشغّل Node **266/266** (223 + 43 جديدًا)؛ فحصا SQL الساكنان 39/39 و30/30؛ `unzip -t` و`python zipfile.testzip()` على ZIP بناه المُجمِّع (CRC سليم، بصمة الملف داخل الأرشيف مطابقة، الاسم العربي للمحتوى سليم).
- **اختبار طفرات** (كسر الشيفرة الجديدة عمدًا): 7/7 أُمسكت — إزالة منع المديرة، الوثوق بـ`teacherId` من الجسم، كشف `storageKey`، رمز فشل متمايز، إلغاء فحص البصمة، إلغاء فحص الكائن المفقود، قبول أي حالة HTTP من خدمة المصادقة (الأخيرة لم تُمسك أولًا فأضفتُ اختبارًا).
- **`tsc --strict --noUnusedLocals`** نظيف على الملفات الجديدة، **بتحفّظ:** مترجم TypeScript 6.0.3 المحلي مع `@types/node` من حزمة أخرى وتعريف vitest مبسّط، **لا** سلسلة المشروع.
- **بديل لا يُحسب نجاحًا حقيقيًا:** كل اختبارات `api.test.ts` تستعمل خدمات/قاعدة/`fetch` بديلة؛ اختبارات القاعدة في `uploadService/psqlDb/pgAuthStore/releaseOverview` ما زالت نائبة هنا.
- **لم يُشغَّل إطلاقًا:** vitest الكامل، `npm run typecheck`، `npm run build`، `build:review`، اختبارات الواجهة، أي SQL على أي قاعدة، تزامن `recordFailure`، أي اتصال حقيقي، Windows.

## 5) قرارات تنتظركِ (توقّفتُ عندها ولم أغيّر شيئًا)
1. **تطبيق مسودة `006_teacher_sessions`** (جدول جلسات + فهرس فريد على `code_hash`): تغيير في قاعدة البيانات؛ بدونه `PgAuthStore` لا يعمل على قاعدة. لن أطبّقها دون موافقتكِ.
2. **أثر دائم لمن أفرجت عن جلسة:** `ownerRelease` تسجّل في `upload_attempts` دون هوية المنفِّذة؛ تدقيق الهوية الآن عبر `audit` غير الدائم. إضافة عمود/جدول تغيير في القاعدة — أحتاج موافقتكِ وتصميمًا.
3. **مخطط مسارات الأرشيف:** افترضتُ معرّفات فقط (بلا أسماء معلمات). وهل يدخل الاسم الأصلي للملف في البيان؟ (يغيّر صيغة `manifest.csv`.)
4. **`exposePendingKey`** مغلق افتراضيًا؛ يُحسم مع DP-03 (طريقة الرفع).
5. قرارات `§9` من تصميم الدخول، وتعريف `overview`، و`final_key_conflict` وقيد `outcome`، و`npm audit` (من r18، دون تغيير).
