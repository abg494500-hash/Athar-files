# تقرير الدفعة (0.6.17، حزمة r26) — المانع الفعلي أمام إصلاح الثغرات وما فُعل حياله

## المانع المحدد
1. **لم تُجمع أدلة التدقيق.** طلبتِ فحص «الأدلة التي جُمعت بالفعل»، لكن لا `evidence.json` ولا `audit.json` ولا `package-lock.json` المحلي وصلني. الرفع يحوي فقط لقطات شاشة (3 صور فريدة، بعضها مكرّر 7 مرات) **تُظهر أن Windows Explorer رفض فك حزمة r25**: «Access to the compressed (zipped) folder is denied. Before you can extract files, you must change the permissions…». أي أن أمر جمع الأدلة لم يُشغَّل أصلًا.
2. **لا سجل npm عندي**: `npm view vite version` و`curl https://registry.npmjs.org/vite` فشلا، ولا `node_modules` ولا ذاكرة npm. فلا يمكنني تثبيت أو تحديث أو تشغيل `npm test`/`build`/`audit`، ولا توليد `package-lock.json` صحيح (يحتاج بصمات السجل). **تعديل أرقام الإصدارات دون قفل ناتج عن npm سيخلق قفلًا غير متّسق وغير موثوق**، وهذا ما ينهاه بند 7 في طلبكِ.

## ما فحصتُه وما وجدتُه
- **أرشيف r25 نفسه** (441 مدخلًا، 101MB): لا محارف ممنوعة على Windows، لا أسماء محجوزة (CON/AUX…)، لا تصادم أحرف كبيرة/صغيرة، لا أسماء عربية، أطول مسار 76 محرفًا، ولا ZIP64؛ بنيته مطابقة لـr24 الذي فككتِه ونجحت عليه اختباراتكِ (476). **الاستنتاج: الخطأ بيئي على الأرجح** (فك داخل مجلد محمي بـControlled folder access/OneDrive، أو ملف محجوب Mark-of-the-Web، أو فوق مجلد فيه ملفات مقفلة، أو نقل ناقص عبر واتساب). **غير مؤكد** لأني لا أرى جهازكِ؛ التجارب مرتبة في `docs/WINDOWS_ZIP_EXTRACT_AR.md`.

## الاختبارات
**نُفِّذ هنا:** مشغّل Node البديل **409/409** (ليس vitest)، `tsc` للخادم والأدوات، الفحوص الساكنة (بيئات الاختبار 4/4، SQL 39/30/28، التوافق، الأسرار 10/10، المولَّد مطابق)، وفك الحزمتين الجديدتين في مجلدين منفصلين مع إعادة التشغيل. **لم يُنفَّذ:** أي أمر npm حقيقي، `npm test` (vitest)، `npm run build`، `npm audit`.
