# جداول الرفع المقترحة (5.1) — للاعتماد قبل أي SQL نهائي

**مبدأ:** لا أحذف قرارًا سابقًا ولا أعيد تفسيره. أبقي `upload_sessions` و`versions` كما في `001`، وأضيف فقط. نص SQL التفصيلي مسودة في `drafts/004_upload_tables.DRAFT.sql` (غير منفَّذة وغير مجرَّبة على PostgreSQL، وتبقى خارج `database/`).

| الجدول | وظيفته | التغيير |
|---|---|---|
| `upload_sessions` | جلسة رفع واحدة: من بدأها، متى، ما أُعلن، حالتها، متى تنقضي، وما قيس عند التحقق | **موجود**؛ أضيف: مفتاح التكرار، حالة التسليم عند البدء، أزمنة الاستلام والتحقق، الحجم وSHA-256 المقاسان، نتيجة التحقق، وقت الإنهاء، وقيود اتساق الحالة والأسباب |
| `versions` | الإصدار المسجّل نهائيًا | **موجود**؛ أضيف `upload_session_id` فريدًا (جلسة واحدة ← إصدار واحد) وقيدًا يمنع إصدار ملف بلا تحقق وبلا جلسة (يعالج G-4) |
| `upload_attempts` | سجل محاولات الرفع بكل نتائجها، ومنها ما لا ينشئ جلسة | **جديد**؛ للمالكة قراءة فقط، والكتابة بالخادم؛ على نمط `login_attempts` |
| `upload_parts` | أجزاء رفع متعدد/مستأنف | **مؤجَّل عمدًا**: يعتمد على DP-03 غير المحسوم؛ لا أضيف جدولًا لطريقة لم تُقرَّر |

**ما تُحقّقه هذه الإضافات:** التحقق من الملف قبل التسجيل (قيد + دالة)، تسجيل المحاولات، ومنع التكرار (فريدان). **ما لا تحققه وحدها:** الموعد وعزل المعلمات (خادم).

- **D-10 احتفاظ `upload_attempts`:** (أ) يُمسح بعد مدة قابلة للضبط على نمط `login_attempts` (أقترح 90 يومًا افتراضيًا مؤقتًا) · (ب) إضافة فقط بلا مسح على نمط `audit_log` (لا مسح ممكن).
- **اعتماد الجداول:** هل أعتمد الشكل أعلاه أساسًا للـSQL النهائي في 5.2؟ أم تريدين تعديلًا؟

## حالة الاعتماد (محدَّثة 2026-10-20، A-55)
**موافقة مبدئية مشروطة، وليست اعتمادًا نهائيًا للـSQL.** شرطها مراجعة التوافق مع القرارات السابقة؛ وقد أُجريت (قراءة ساكنة، دون تنفيذ) ووجدت 9 ملاحظات **C-1…C-9** في `PHASE5_1_REVIEW.md` القسم 3، منها:
- **C-1:** `upload_attempts` يحتاج `grant select … to authenticated` (لأن `003` يسحب كل الصلاحيات ثم يمنح صراحةً)؛ دونه لا تقرأ المالكة السجل.
- **C-2/C-3:** حماية `upload_attempts` و`upload_sessions` من التعديل/الحذف (إضافة فقط) — C-3 يغيّر `on delete set null` وهو ما كان مقصودًا في المسودة، فيحتاج موافقتك.
- **C-5:** فهرس فريد جزئي لجلسة نشطة واحدة لكل (معلمة، فصل، خانة) — اقتراح جديد يحتاج موافقتك.
**لا SQL نُفِّذ.** لم يُغيَّر أي قرار سابق. القرار D-10 (90 يومًا): مبدئي بلا حذف تلقائي.
