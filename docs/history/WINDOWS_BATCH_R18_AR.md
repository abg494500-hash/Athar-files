# تشغيل اختبارات الدفعة r18 على Windows (خطوة واحدة في كل مرة)

> لم يُجرَّب هذا الدليل على Windows بعد؛ هو مكتوب من المعطيات المعروفة. أرسلي لي ناتج كل خطوة كما يظهر، نجح أو فشل. **لا تنفّذي SQL على Supabase ولا تُدخلي مفاتيح حقيقية في أي خطوة.**

## الخطوة 1 — فتح المجلد
فكّي ضغط `athar-handoff-r18-v0_6_9.zip`، ثم افتحي PowerShell داخل المجلد `athar` (بيمين الفأرة على المجلد ← «فتح في Terminal»).

## الخطوة 2 — التأكد من Node
اكتبي `node -v`. المطلوب 22 أو أحدث (للمشغّل البديل)، و20 على الأقل للمشروع. أرسلي الناتج.

## الخطوة 3 — تثبيت الاعتماديات
اكتبي `npm install` (وليس `npm ci`). أرسلي آخر 15 سطرًا من الناتج. (`@types/node` أُضيف في r17 ولم يُتحقق منه.)

## الخطوة 4 — فحص الأنواع
`npm run typecheck` ثم أرسلي الناتج كاملًا. هذا أول تشغيل حقيقي له منذ r13.

## الخطوة 5 — اختبارات المشروع
`npm test` وأرسلي سطر الخلاصة (عدد الملفات والاختبارات الناجحة والفاشلة). اختبارات القاعدة ستمرّ بنائبٍ لأنك لا تملكين PostgreSQL محليًا بعد؛ هذا متوقع.

## الخطوة 6 — المشغّل البديل (اختياري، يحتاج Node 22+)
```
node --experimental-strip-types --no-warnings --import ./scripts/node-test-runner/register.mjs --test server/test/archive.test.ts server/test/teacherAuth.test.ts
```
اختبار «تحقق مستقل بأدوات النظام» داخل `archive.test.ts` يحتاج `unzip` و`python3` في PATH؛ إن لم يوجدا على Windows **يمرّ بلا تنفيذ** (يتخطّى تلقائيًا) وهذا ليس نجاحًا حقيقيًا لهذا الجزء.

## الخطوة 7 — البناء
`npm run build` ثم `npm run build:review`، وأرسلي الناتج.

## ما لا يجوز قبل اكتمال ما سبق
لا نشر، ولا إنشاء مشروع Supabase أو حساب Cloudflare، ولا بيانات معلمات حقيقية. قائمة ما قبل النشر الكاملة تبقى في `docs/RELEASE_GATE_REPORT_AR.md` وتحتاج تحديثًا بعد نتائج هذه الخطوات.
