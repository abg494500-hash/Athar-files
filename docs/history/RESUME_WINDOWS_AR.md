# تعليمات الاستئناف (Windows) — حزمة r13

1. افتحي المحادثة الجديدة وأرفقي `athar-handoff-stage3-wip-redesign-v0_6_4-r13.zip`.
2. اطلبي قراءة بالترتيب: `HANDOFF.md` ← `NEXT_STEPS.md` ← `PROJECT_STATUS.md` ← `docs/RELEASE_GATE_REPORT_AR.md` ← `docs/REPORT_0_6_3_AR.md` ← `docs/REDESIGN_REPORT.md` ← `docs/phase5/STAGE3_REPORT.md` ← `DECISIONS_LOG.md` (A-83 وA-91) ← `PROJECT_RULES.md`.
3. نفّذي `docs/DESIGN_PREVIEW_AR.md` وأرسلي نتائج `typecheck` و`npm test` و`npm run build` كما هي **قبل أي إصلاح**. ثم `docs/WINDOWS_TEST_STAGE3_AR.md` لإكمال اختبارات المرحلة 3.
4. القواعد: لا انتقال إلى المرحلة 4 قبل اكتمال المرحلة 3؛ لا حسابات ولا `bootstrap_staff` ولا تعديل Supabase/SQL ولا مفاتيح دون موافقتكِ الصريحة؛ الترقيم المعتمد A-83 (سبع مراحل) لا يتغير.
5. النسخ السابقة: `previous-versions/` تحوي حزمة r12 (وفيها r7 وr9 وr10 مضمّنة)؛ r11 هي ملفكِ المرفق السابق فاحتفظي بها. لا تُحذف.
