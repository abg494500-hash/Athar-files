# دليل إدارة المعلمات

الصفحة: **المعلمات والأكواد** (للمالكة).

## البحث والتصفية والترتيب
- **بحث في المعلمات:** بالاسم أو المادة.
- **تصفية بالحالة:** الكل / فعّالة / موقوفة / بلا رمز دخول.
- **ترتيب القائمة:** الحالة ثم الاسم / الاسم / المادة.

## إضافة وتعديل
**إضافة معلمة** (الاسم 3 أحرف فأكثر، والمادة). **تعديل** لتغيير الاسم أو المادة. **اللون** لتغيير لون الصورة الرمزية.

## الإيقاف وإعادة التفعيل
داخل **تعديل**: **إيقاف المعلمة** يمنع دخولها فورًا ويبقي ملفاتها. **إعادة تفعيل المعلمة** تعيدها. (بعد الإعادة قد تحتاج رمزًا جديدًا إن كان ملغى.)

## رموز الدخول
- **إصدار الرمز** يعرض **رمزًا واحدًا** (مثل SA-12) **مرة واحدة فقط** (لا يُخزَّن ولا يُسترجع). انسخيه فورًا. المالكة والمديرة كلتاهما تسجّل المعلمات وتصدر الرموز؛ حذف المعلمة للمالكة وحدها.
- **إعادة إصدار** يبطل القديم. **إلغاء الرمز دون إصدار جديد** يمنع الدخول وينهي الجلسات.

## الحذف
**حذف المعلمة** (داخل تعديل): يُمحى الاسم ويبطل الدخول، **ولا يُسمح** إلا إذا كانت **كل** تسليماتها داخل أرشيف سنوي مسجَّل وتحقق منه (كل أجزائه). المعلمة التي لها ملفات غير مؤرشفة لا يُحذف شيء من بياناتها.
